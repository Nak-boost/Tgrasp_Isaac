# E2：全局 voxel＋交互历史（2026-10-15）

新 E2 替换原先使用物体几何与 PointNet 的 E2。当前 E3 的配置、网络参数布局和行为保持不变；E4 的原历史编码路径保留，E5 仍可使用原几何编码器。

## 输入与网络

| 输入 | 实现 |
|---|---|
| 全局地图 | 复用 E3 的 2 通道、32×32×16 voxel 与 CNN＋Transformer。 |
| 短历史 | 8 帧，每 3 步取一帧，旧到新为 t−21、t−18、…、t；60 Hz 下跨度 0.35 秒。 |
| 每帧 130 维 | 传感器位置 42、二值触觉 14、关节位置/速度 44、手部位姿 6、上一基座指令 6、目标跟踪误差 18。 |
| 目标误差 | 刚执行的平滑、限幅后关节目标减执行后的实际位置，再除以该关节上下限之差；替换原来的 18 维手指动作。 |
| 长期记忆 | 唯一的 GRUCell，每个控制步读取最新 130 维，更新 128 维隐藏状态；回合结束后清空。 |
| 估计位置 | 保留触觉估计的相对位置 3 维。 |

8×130 维历史展平后复用普通 MLP；与地图特征、估计位置和 GRU 摘要拼接，再直接进入 Actor/Critic。没有融合后的第二个 GRU，没有局部 voxel，也不向策略输入真实物体状态或几何。

沿用 PPO 的 `prop` 分支接口存放 1040 维短历史，避免修改 rollout storage。当前帧直接从短历史尾部读取供 GRU 使用，无需再次存储。总观测维度为 1040＋3＋32768＝33811。

环境维护 22 帧缓存，每步更新；新回合缺少的旧帧填零。PPO 继续使用现有循环训练、隐藏状态存储及 done 掩码；摘要跨 rollout 保留，反向传播仍在 rollout 内截断。

## 配置与兼容性

入口为 `cfg/shadow_hand_grasp_dexrep_E2.yaml`。历史配置为 `length: 8`、`stride: 3`、`persistent_memory: True`、`memory_hidden_dim: 128`；现有 `--history_length 4/8/16` 参数继续有效。改变 length 后需要重新训练相应输入维度的模型。

奖励、碰撞过滤、物体集合、随机范围及 episode 设置沿用本次修改前的 E3：2 个物体、XY ±0.25、1600 步 episode、32 步 rollout。保留 E3 原有的训练奖励（包括弱真实位置接近奖励），本次不调整奖励。未启用非对称 critic。

旧 E2 checkpoint 与新结构不兼容，应使用旧代码和旧配置回放。E3/E4 的权重结构未改变。主项目的这次实现未同步到 TGrasp_B。

## 验证

- 修改前后的 E3/E4 网络在相同初始化及输入下，权重、动作、价值和隐藏状态逐元素一致；E3 配置与修改前逐字节一致。
- 检查了抽帧索引、零填充、单环境历史清空、目标误差对齐、4/8/16 帧尺寸，以及循环 PPO 的逐步/批量结果和各分支反向梯度。
- GPU 使用 16 个环境完成 2 轮 PPO 更新并保存 `model_2.pt`；权重重新加载后通过 48 步仿真，验证了实际目标误差、抽帧和回合重置。
- 标准训练入口在完成更新和保存后出现原生退出段错误；E3 对照也复现。独立回放全部断言和显式 simulator 释放完成后，进程退出仍出现该问题。本次未修改资源释放流程，退出问题尚未解决。
- 这些是功能检查，不代表已验证新结构的训练效果；未启动正式长训练。
