# 2026-10-16：E2/E3非对称Actor–Critic

主项目E2、E3和B项目E3已接入特权critic。Actor的voxel、触觉、本体、位置估计及历史结构保持原样；奖励、episode长度、物体范围和PPO rollout长度没有调整。

## 结构与输入

```text
原Actor观测 → 原编码器/GRU → Actor → 动作均值、噪声
                        └→ 拼接30维特权状态 → 原Critic MLP → V
```

特权状态不进入共享编码器、GRU、动作均值或噪声分支。critic仍读取原有地图/历史特征，以反映策略的记忆。没有增加第二套CNN、GRU或特权编码器。共享编码器仍接受价值损失的训练梯度，这不等于执行时读取特权输入。

环境通过现有的`states_buf/get_state()`提供独立状态，不扩展Actor的`obs_buf`。状态在每次物理步的观测与奖励计数更新后生成。坐标使用与地图一致的环境固定坐标轴；掌心采用palm刚体中心。

| 维度索引（从0开始） | 信息 | 处理 |
|---|---|---|
| 0–2 | 物体真实位置减掌心位置 | 除以原相对位置尺度，当前为[0.35, 0.35, 0.40] m |
| 3–6 | 物体真实姿态 | 环境坐标系四元数，xyzw |
| 7–9 | 物体线速度 | m/s |
| 10–12 | 物体角速度 | 乘原速度观测尺度0.2 |
| 13 | 回合初始物体高度减桌高 | 除以抬升目标高度 |
| 14 | 当前物体高度减回合初始高度 | 除以抬升目标高度，保留负值 |
| 15 | 剩余episode时间比例 | 使用实际progress计数，限制在[0,1] |
| 16 | 连续有效抓取接触步数 | 除以有效抓取要求步数，限制在[0,1] |
| 17 | 连续抬升达标保持步数 | 除以成功保持要求步数，限制在[0,1] |
| 18 | 接触后连续失触步数 | 除以失触终止步数，限制在[0,1] |
| 19–20 | 本回合是否接触过、是否得到过有效位置估计 | 0/1 |
| 21–29 | 九宫格访问标记 | 0/1；未启用区域机制时为0 |

沿用环境接口的观测截断，当前范围为[-5,5]。首版没有添加质量、摩擦、物体ID或点云；这些不是当前非对称critic接入的必要条件。

启用开关为现有的`env.asymmetric_observations: True`。环境初始化后自动确定`privileged_obs_dim=30`和`numStates=30`，不需要手工改Actor维度或训练配置中的另一套asymmetric开关。

- B项目：`cfg/shadow_hand_grasp_dexrep_E3.yaml`、`cfg/shadow_hand_grasp_dexrep_E3_1014_exp4.yaml`。

历史训练目录中的source_snapshot和其他历史实验配置保留。关闭该开关即可新建原对称结构；带特权critic的新权重需使用匹配的非对称配置加载。B项目原有的粗全局voxel CNN设置和旧E2实现没有被替换。

## PPO与权重兼容

- 在动作执行前复制对应的特权状态，防止环境步进覆盖后把下一帧真值错误地写入当前转移。
- PPO缓存独立保存30维状态；普通和循环小批次、末步价值自举均接通。循环更新按同一时间/环境索引取状态，并沿用原done掩码重置隐藏状态。
- 接收同结构的旧对称权重时，仅自动扩展critic第一层输入权重，新增30列置零；Actor、噪声、GRU和原critic权重严格加载。初始化时维持旧价值函数，随后通过PPO学习使用真值。
- 不兼容的其他网络形状仍会严格报错，不使用宽松加载掩盖错误。新权重可正常保存、加载与续训。
- 执行时使用`act_inference(observations, hidden_state)`，不需要特权状态。训练用`act/get_value/evaluate*`在启用非对称critic后必须提供对应真值。
- 沿用原PPO保存机制：权重与向上监督进度可恢复，优化器和仿真状态不会随checkpoint恢复。本次没有改变这一行为。

1024环境、32步rollout时，新增特权缓存为3.75 MiB；critic第一层当前增加30720个参数。总显存还包括梯度、优化器和临时张量，不能将缓存大小当作全部增量。

## 验证

网络检查覆盖：对称配置回归、E4输出不变、旧权重迁移、改变真值不影响Actor/噪声/GRU、critic对真值的响应与梯度、循环序列及done掩码一致性、无循环配置、保存加载和缓存复制隔离。

三个目标配置的真实Isaac Gym短PPO验证均通过：每组16环境、32步rollout，完成3次更新、96个采样步和192次回合结束，并验证保存后恢复。测试episode缩短至8步以覆盖重置。短测试仅验证实现链路，不代表新结构已提高训练成功率。
